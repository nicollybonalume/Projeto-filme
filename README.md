# 🎬 Projeto HTML - Filme

Simplesmente Acontece

## 📚 Curso/Turma

## 🎯 Objetivo do Projeto

Desenvolver uma página web utilizando HTML, aplicando corretamente as principais tags de estruturação, com o objetivo de organizar e apresentar informações, imagens, textos e links de forma clara, semântica e bem estruturada, tendo como referência o filme selecionado.

## 🛠️ Tecnologias Utilizadas

* HTML5

## 📌 Descrição da Página Desenvolvida

A página web desenvolvida tem como finalidade apresentar informações relevantes sobre o filme *Simplesmente Acontece*, incluindo sua sinopse, imagens representativas, personagens principais e links complementares. A estrutura do projeto foi organizada de forma lógica e hierárquica, utilizando boas práticas de marcação HTML para garantir legibilidade, organização do conteúdo e uma navegação intuitiva para o usuário.
